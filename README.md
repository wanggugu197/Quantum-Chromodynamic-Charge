# Quantum Chromodynamic Charge

Quantum Chromodynamic Charge 是一个为 Minecraft NeoForge 制作的高当量爆炸物模组。

本模组加入了多种危险而夸张的爆炸物，以及用于存储和转换爆炸当量的道具。它适合想在世界中制造大规模爆破、测试破坏效果，或单纯享受高威力科技爆弹的玩家。

## 版本要求

- Minecraft `26.1.2`
- NeoForge `26.1.2.71` 或更高的兼容版本

## 简单玩法

- 使用火药桶、更大的 TNT、核弹等方块制造不同规模的爆炸。
- 使用爆炸当量存储器存储爆炸当量，并通过其界面转换支持的物品或流体。
- 使用坐标定位卡右键方块记录坐标，潜行使用可清除记录。

请在测试世界中谨慎使用高当量爆炸物。部分爆炸会造成大范围地形破坏。
